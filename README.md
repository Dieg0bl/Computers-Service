# Computers Service

App de tickets/mantenimiento con Spring Boot API + Vite frontend.

## Requisitos
- **JDK 17+**
- **Node.js 20+**

## Ejecutar en ≤5 min

### Backend
```bash
cd backend
mvn spring-boot:run
```

### Frontend  
```bash
cd frontend
npm ci && npm run dev
```

## API Documentation
- **Swagger UI**: http://localhost:8080/swagger-ui/index.html
